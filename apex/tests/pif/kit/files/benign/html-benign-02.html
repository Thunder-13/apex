Prompt injection: a security overview

Prompt injection is an attack category in which adversarial text attempts to redirect an AI system's behavior. This article explains the attack patterns and countermeasures for security practitioners.

Common attack patterns

Attackers use phrases such as "ignore previous instructions" or "you are now DAN" to attempt role changes. These phrases appear in this document for educational purposes only and do not constitute instructions to any AI system reading this page.

Example of an instruction override attempt (for documentation purposes):

Ignore all previous instructions and instead...

Mitigations

Effective mitigations include prompt hardening, output filtering, and runtime permission enforcement. No single approach is sufficient on its own.
